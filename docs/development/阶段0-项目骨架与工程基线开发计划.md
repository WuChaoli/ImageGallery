# 阶段 0 项目骨架与工程基线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可本地安装、可导入、可测试、可继续扩展的最小 Python package 工程骨架。

**Architecture:** 阶段 0 只定义工程外壳和公开命名边界，不实现 Storage、Dataset、Import、Cleaning 等模块逻辑。包结构以 `src/image_gallery/` 为核心，`tests/`、`examples/`、`notebooks/` 作为后续阶段的验证入口，所有业务模块先保留空包和清晰导出边界。

**Tech Stack:** Python 3.10, setuptools, pytest, ruff, mypy, Jupyter Notebook 目录入口.

## 2. 范围边界

阶段 0 只做工程基线：

1. 建立 `pyproject.toml`。
2. 建立 `src/image_gallery/` 包结构。
3. 建立 `tests/`、`examples/`、`notebooks/` 基础目录。
4. 建立最小测试、格式化和类型检查命令。
5. 建立第一批公开 API 的命名边界。

阶段 0 不做以下内容：

1. 不实现 Storage 对象读写。
2. 不实现 Dataset 文件读写。
3. 不实现 raw schema 校验。
4. 不实现图片导入、元数据抽取、URL 下载。
5. 不实现 CleaningRecipe、ExecutionPlan、ExecutionPack、node_result、MergePolicy。
6. 不引入服务端 API、Web 页面或数据库。
