# 文档权威性与同步策略

## 权威来源

| 问题 | 权威来源 |
|---|---|
| 产品当前承诺什么行为 | `openspec/specs/` |
| 产品正在怎样变化 | `openspec/changes/` |
| 当前实现实际上是什么 | 代码、类型、测试 |
| AI 应怎样修改仓库 | 根与模块 `AGENTS.md` |
| 人如何安装和使用 | 根或模块 `README.md` |
| 历史设计 | 归档文档，仅供追溯 |

判断“应该是什么”时以 OpenSpec 为准；判断“现在能做什么”时以代码和测试为准。不得把未实现的 change 内容写成 README 或模块 `AGENTS.md` 的当前能力。

## 文档影响矩阵

| 变更 | 模块 AGENTS | README | 根 AGENTS |
|---|---|---|---|
| 内部 Bug 修复且行为不变 | 通常不更新 | 不更新 | 不更新 |
| 内部重构且边界不变 | 导航失效时更新 | 不更新 | 不更新 |
| 模块职责变化 | 更新 | 用户可见时更新 | 全局边界变化时更新 |
| 公共 API 增删或用法变化 | 更新推荐入口和约束 | 更新 | 通常不更新 |
| 输入输出或异常语义变化 | 更新关键契约 | 用户可见时更新 | 不更新 |
| 模块依赖方向变化 | 检查两侧模块 | 通常不更新 | 全局边界变化时更新 |
| 安装、配置或命令变化 | 相关模块更新 | 更新 | 全仓通用时更新 |
| 顶层模块增删 | 创建、更新或删除 | 用户可见时更新 | 更新模块索引 |
| 测试或验证边界变化 | 更新 | 通常不更新 | 全局策略变化时更新 |

## 内容边界

### 根 AGENTS.md

只维护仓库级治理、全局边界、关键命令、文档权威性和模块导航。不要展开模块 API。

### 模块 AGENTS.md

维护职责与非职责、稳定能力摘要、推荐公共入口、关键契约、依赖边界、测试入口和文档导航。不要维护逐文件索引、完整签名或一次性任务状态。

### README.md

维护人类用户需要的安装、配置、使用示例和限制。完整 API 以代码签名、类型和 docstring 为准。

### 排除项

- 不创建或维护 `docs/CODEMAPS.md`。
- 不更新已废弃的 `docs/superpowers/`。
- 不把测试用例逐条复制到文档。
- 不因为文件新增就机械更新文档。
