# 模块 AGENTS.md 模板

```markdown
# `<module>/` 模块指南

## 职责

- 说明模块负责什么。
- 说明模块明确不负责什么。

## 当前能力

- 只列已实现并有代码或测试证据的稳定能力。

## 公共入口

- 指向包级 `__init__.py` 导出的推荐入口。
- 不复制完整函数签名。

## 核心契约与边界

- 记录不容易从签名发现、破坏后影响较大的语义。
- 记录允许和禁止的依赖方向。

## 开发与验证

- 指向相关单元测试、集成测试和最小验证命令。

## 相关文档

- 当前产品行为：`openspec/specs/<capability>/spec.md`
- 面向用户的用法：`README.md` 或模块 README
```

普通模块保持简洁；空命名空间只需说明其保留目的、当前没有公共能力，以及禁止提前添加假设性实现。
